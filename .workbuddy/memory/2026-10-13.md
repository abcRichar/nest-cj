### 本机环境坑（重要，跨项目复用）
- `/tmp` 在 Git Bash 对 node 不可见，临时文件一律放项目内（如 `.tmp/`）。
- `taskkill` 参数在 Git Bash 会被路径转换，`taskkill /F /PID` 需配 `MSYS2_ARG_CONV_EXCL="*"`。
- **vite preview 与 vite build 不能同时跑**：preview 持有 dist 文件句柄会让 build 写入阻塞挂死（实测 7 分钟无进展）。先停 preview 再 build。
- dev server 验收 SPA 会因「依赖预构建触发 reload」造成首屏空白假象，验收请用 build+preview（preview 也配 proxy，见 vite.config.ts）。

### 踩到并修复的真实 bug（冒烟测试的价值所在）
1. `MessageQueryDto` 未声明 `conversationId`，被全局 ValidationPipe `whitelist:true` 剥离 → 历史消息接口永远 400。教训：**DTO 必须显式声明会被读取的每个字段**。
2. 前端 `http.ts` 请求拦截器只读 `elp_token`，管理端接口必 401。改为按 url 前缀 `/admin` 取 `elp_admin_token`；401 清理也按端区分。
3. `http.ts` 调用未导入的 `hmacSignHex`（应为 `safeHmac`）——只靠 tsc 才能发现。
4. 共享包单 CJS 产物无法被 Vite 按名导入（Rollup 报 "is not exported"）→ 双产物 `dist/cjs` + `dist/esm`，exports 字段按 import/require 分发。**tsbuildinfo 与 dist 不同步时 tsc 会静默跳过 emit**，build 脚本先 rm 两者。
5. `alipay checkNotifySign` Mock 模式跳过验签在生产环境是漏洞 → 仅非生产允许，生产直接拒绝。
6. Three.js `TextureLoader` 没有 dispose（ts 报错）；TextureLoader 未用即删。
